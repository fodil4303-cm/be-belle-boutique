# Be Belle Boutique | طقم الشتاء المحتشم الملكي (2 قطع) 🇩🇿

صفحة هبوط تسويقية متكاملة مع لوحة تحكم إدارية مخصصة (Admin CMS v3.0) لمتجر الأزياء النسائية الفاخرة **Be Belle Boutique**.

## المميزات الرئيسية:
- **نظام الدفع عند الاستلام (COD):** دعم كامل وشامل لكافة الـ 69 ولاية جزائرية مع حساب التوصيل تلقائياً والتوصيل المجاني لعرض الطقمين.
- **تصميم Thumb-Zone فائق التوافق:** مهيأ بالكامل للهواتف الذكية مع شريط شراء سفلي دائم ونافذة طلب سريع منبثقة (Bottom-Sheet Drawer).
- **لوحة تحكم كاملة (Admin CMS v3.0):**
  - التحكم في الشعار ورفعه مباشرة.
  - استبدال رسومات المعرض بصور حقيقية من الجهاز.
  - تعديل الأسعار، العروض، ونسب الخصم.
  - تعديل كافة النصوص والمواصفات.
  - إدارة آراء الزبائن والأسئلة الشائعة (إضافة / تعديل / حذف).
  - سجل طلبيات حي (Live CRM) مع إمكانية الاتصال بالزبون عبر الهاتف أو الواتساب بنقرة واحدة وتصدير البيانات كـ Excel/CSV.
  - إمكانية تصدير نسخة HTML مدمجة بالكامل جاهزة للنشر على أي استضافة.

## ملفات المشروع:
- `index.html`: صفحة الهبوط والمتجر الرئيسي للزبائن.
- `admin.html`: لوحة التحكم الإدارية.
- `assets/`: مجلد الشعار والصور والأيقونات.
- `wilayas.json`: قاعدة بيانات الـ 69 ولاية مع تكاليف التوصيل.
